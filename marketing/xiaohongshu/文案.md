## 正文

开黑前一分钟，才发现电脑还跑在「平衡」模式。

Win11 把「高性能」从设置里藏了，切一次要点：右键桌面 → 显示设置 → 电源和睡眠 → 其他电源设置 → 选计划。五步，一天好几遍。

我写了个 30 KB 的小工具，把这件事压成一个键。

**Alt + Q**，日常 → 游戏 → 静音 → 日常，循环。
屏幕底部会闪一条提示，0.9 秒，告诉你现在切到哪一档。点击穿透、不抢焦点，不打断手上的操作。

三个我自己最在意的点：

**1. 快**
一开始用 powercfg 命令行切换，一次要起三个进程，实测中位数 302 ms。改成直接调系统电源接口后降到约 206 ms——剩下那 0.2 秒是 Windows 自己应用电源策略的时间，绕不过去。按下到屏幕浮出提示，基本无感。

**2. 轻**
整个程序就是一个 .ahk 脚本，常驻内存 17 MB（私有内存 4 MB）。不起服务、不装驱动、不留后台进程。关掉就是关掉，进程表里立刻消失。

**3. 开机自启**
托盘菜单一键开关，放在 shell:startup 里，不需要管理员权限。登录就在托盘里，不用每次手动开。

**系统里没有「高性能」怎么办？**
它会先试原生 GUID，失败就按原生模板复制一份改名，再把新 GUID 写回配置。不会拿「平衡」复制改个名字冒充——那样风扇和帧数完全是两回事。

装法有两种：

**丢给 Agent**——把第 7 张图里那段话发给 WorkBuddy / Claude Code / Cursor 之类的助手，它会自己下载、解压、放运行时、启动验证。

**自己装**——装 AutoHotkey v2 → 下载仓库解压 → 双击 .ahk。仓库里也带了 `install.ps1`，能跑 PowerShell 的 Agent 一条命令就完事。

MIT 协议开源，代码在 GitHub：`jm17647-dna / PowerModeSwitcher`（主页简介有直达链接）

你一天要切几次电源？评论区报个数。
